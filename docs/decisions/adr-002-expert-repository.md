# ADR 002 — 전문가 데이터 소스 단일화

상태: proposed
날짜: 2026-06-08

## 결정
`experts` 데이터는 Supabase를 단일 소스로 사용한다.
`mock-repository.ts`는 레거시로 분리한다.

## 이유
- 실제 운영 데이터와 테스트 데이터가 섞이면 매칭 품질 판단이 어려움
- RLS 정책으로 공개/비공개 접근을 명확히 분리 가능
- SQL 샘플 데이터가 이미 존재하므로 전환이 빠름

## 결과
- repository.ts 인터페이스 유지, 구현체를 Supabase로 제한
- 필요 시 테스트 전용 시드를 위한 별도 seed 스크립트 사용
