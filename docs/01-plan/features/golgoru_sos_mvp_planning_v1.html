골고루 SOS MVP 기획 문서 v1

사용자의 긴급·상담 상황을 AI가 이해하고, 적합한 전문가를 추천한 뒤 전화·문자·상담 요청으로 연결하는 모바일 서비스의 1차 기획 확정본입니다.

Flutter 모바일 앱 Supabase 백엔드 Gemini AI 추천 Vercel + Next.js 웹 채널

1. 서비스 정의

골고루 SOS는 사용자가 본인의 상황을 자연어로 입력하거나 말하면, AI가 의미를 분석하여 적합한 전문가를 3~5명 추천하고, 사용자가 원하는 방식으로 전문가와 연결될 수 있게 하는 서비스입니다.

핵심 방향: 단순 전문가 검색이 아니라 “상황 기반 AI 전문가 추천·연결 서비스”로 정의한다.
사용자 상황 입력
→ Gemini 기반 의미 분석
→ 전문가 3~5명 추천
→ 전문가 프로필/미니홈피 확인
→ 전화 / 문자 / 상담 요청
→ 전문가 앱 푸시 알림
→ 전문가 수락·거절·간단 답변
→ 필요 시 전화 상담 연결

2. 전체 기술 아키텍처

확정 구조: Flutter + Supabase + Gemini API + Vercel/Next.js

3. 모바일 앱 정책

앱은 초기에는 하나의 Flutter 앱으로 개발한다.

일반 사용자 기능

  • 상황 입력
  • 음성 또는 텍스트 입력
  • AI 전문가 추천 결과 확인
  • 전문가 미니홈피 보기
  • 전화하기, 문자 보내기, 상담 요청하기

전문가 기능

  • 전문가 계정 로그인
  • 상담 요청 푸시 알림 수신
  • 상담 요청 상세 확인
  • 수락/거절
  • 간단 답변 메시지 전송
  • 현재 상담 상태 변경

4. 회원 정책

MVP 단계에서는 A안: 비회원도 사용 가능으로 간다.
  • 회원가입 없이 상황 입력 가능
  • 회원가입 없이 AI 추천 확인 가능
  • 회원가입 없이 전문가 미니홈피 조회 가능
  • 향후에는 회원가입 기반 또는 단계적 가입 정책으로 업그레이드 가능
단, 실제 상담 완료 후 좋아요 평가를 남기는 기능은 가입 사용자 기반으로 운영한다.

5. AI 추천 정책

사용자가 어떤 의미로 상황을 설명할지 예측하기 어렵기 때문에, 키워드 검색보다는 Gemini API 기반의 자연어 의미 분석을 활용한다.

추천 수: 기본 상위 3명, 전문가 풀이 충분하면 최대 5명까지 추천한다.

추천 모드

모드추천 우선순위설명
기본 모드 전문 분야 적합도 우선 지역보다 전문 분야와 상황 적합성을 더 중요하게 반영한다.
긴급 모드 전문성 + 지역/거리 + 즉시 대응 가능성 사용자가 긴급 상황임을 선택하면 가까운 전문가와 현재 상담 가능 상태를 더 강하게 반영한다.

AI 추천과 사용자 평가는 구분한다

  • 추천: AI가 상황 분석 후 전문가를 제안하는 행위
  • 좋아요: 실제 상담 후 가입 사용자가 남기는 평가 지표
  • 별점: 도입하지 않음

6. 전문가 등록 및 계정 정책

초기 전문가 등록은 어드민 직접 발굴·검증·등록 방식으로 한다.
  • 어드민이 전문가를 직접 발굴한다.
  • 어드민이 전문가 정보를 입력하고 검증한다.
  • 전문가는 본인 미니홈피 정보를 직접 수정하지 않고 열람 중심으로 사용한다.
  • 향후 서비스 성장 시 전문가 신청 기능을 추가하는 C안으로 확장 가능하게 설계한다.

전문가 계정 활성화

어드민 등록 후 전문가가 초대 링크를 받아 직접 비밀번호를 설정한다.
  1. 어드민이 전문가 기본 정보 등록
  2. 전문가 이메일로 초대 링크 발송
  3. 전문가가 링크 접속
  4. 비밀번호 직접 설정
  5. 계정 활성화
  6. Flutter 앱 로그인

7. 전문가 미니홈피 정책

전문가 미니홈피는 Vercel + Next.js 기반의 독립 웹페이지로 제공한다.
  • 어드민이 전문가 정보를 입력·수정한다.
  • 전문가는 본인 페이지를 뷰 중심으로 확인한다.
  • 사용자가 전문가 카드를 누르면 독립 미니홈피 형태로 열린다.
  • Flutter 앱에서는 WebView 또는 외부 웹링크로 미니홈피를 표시한다.
  • 게시판, 댓글, 전문가 직접 글쓰기는 MVP에서 제외한다.
  • 게시판 기능은 전문가 요청과 시장 반응을 보고 차기 버전에서 검토한다.

미니홈피 표시 정보

  • 전문가명
  • 전문 분야
  • 활동 지역
  • 자격/경력
  • 현재 상담 상태
  • 좋아요 수
  • 전화하기, 문자 보내기, 상담 요청하기 버튼
상담 가능 응답 지연 가능 상담 불가

8. 전문가 상태 관리

C안: 상태 + 운영시간 구조로 관리한다.

내부 관리 정보

  • 평일 운영시간
  • 주말/공휴일 운영 여부
  • 야간 상담 가능 여부
  • 현재 상태

사용자에게 노출되는 상태

  • 상담 가능
  • 응답 지연 가능
  • 상담 불가
상세 운영시간은 추천 알고리즘과 내부 운영에 활용하고, 사용자에게는 현재 상태 중심으로 간단히 노출한다.

9. 전문가 연결 및 상담 요청 정책

전문가 연결 방식은 혼합형(C안)으로 한다.
  • 전화하기
  • 문자 보내기
  • 상담 요청하기

전화 연결을 선호하는 긴급 사용자를 지원하면서도, 전화를 부담스러워하거나 먼저 메시지로 문의하고 싶은 사용자를 배려한다.

상담 요청 처리

  1. 사용자가 전문가에게 상담 요청 발송
  2. 전문가에게 개별 앱 푸시 알림 제공
  3. 전문가가 요청 상세 확인
  4. 전문가가 수락 또는 거절
  5. 전문가가 간단한 답변 메시지 작성 가능
  6. 이후 실제 상담은 전화 연결로 이어질 수 있음
MVP에서는 실시간 채팅방을 만들지 않는다. “상담 요청 + 전문가 답변 메시지”까지만 제공한다.
